# Stamp fonts

These 17 WOFF2 files correspond to the official upstream projects below. All
are licensed under the SIL Open Font License 1.1. The complete license is in
[`OFL-1.1.txt`](./OFL-1.1.txt). Family-specific copyright notices and official
license records are included below.

Binary metadata was checked with FontTools 4.63.0. Every file includes an OFL
URL in its name table. The CSS values are from `../../stamps.css`; the internal
names and axes are read directly from each WOFF2 file.
