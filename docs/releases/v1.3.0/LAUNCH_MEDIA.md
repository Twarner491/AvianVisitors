## Historical X draft: Evolutionary Impressionist

Evolutionary Impressionist redraws 333 birds of western North America as loose, evolved gestures: movement first, field marks still visible.

Built on Matt DesLauriers's work, *Synthetic Gestures: An Evolutionary Sketching Machine*.
