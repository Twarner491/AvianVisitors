# Avian Visitors v1.3.2

Avian Visitors v1.3.2 makes regional bird bundles easier to use and adds a way to remove false detections from your station.

## Bird bundles

Choose one or more regions from the same illustration style. If a bird appears in several selections, the first selected region supplies its artwork.

The Iberian Woodblock bundle now fills missing birds with the original Woodblock artwork, keeping the contributor's illustrations wherever available. Select the bundle again after updating to apply this to an existing installation.

## Correct false detections

Open a bird's recordings and choose **Mark incorrect** to remove a false detection from station and listening-period counts. Admin access and confirmation are required. The recording stays on disk.

## Other fixes

- Smoother Collage refreshes, with retries for images that fail to load.
- Consistent station settings and better protection for existing detections when rerunning setup.
- Working backup controls, a stop action, and clearer shared-microphone setup instructions.
- Restored spectrograms for recordings with localized names or other audio formats.
- Falcons have their own Atlas group, and Settings shows the installed checkout version.

The default image model and illustration style are unchanged.

## Updating an existing station

Use **Tools > Pull latest** or the [documented updater](https://github.com/Twarner491/AvianVisitors/blob/v1.3.2/README.md#updating-an-existing-station). Your current bird bundle stays selected during the update.
